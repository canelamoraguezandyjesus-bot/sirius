# Evolución de Sirius después de 0.1

Esta carpeta contiene la base canónica aprobada para evolucionar Sirius desde el corazón persistente de 0.1 hasta un robot compañero. Desde el 06-10-2026 Sirius es solo el software del robot (ADR-232).

## Estado

- Documento Rector de Evolución Post-0.1: **v1.0 APROBADO** el 22 de julio de 2026, enmendado por su §19 el 8 de septiembre y por su §20 el 6 de octubre de 2026.
- Decisiones EV-001 a EV-023: **APROBADAS**. Las sustituidas o aparcadas lo llevan escrito en su propio apartado.
- Implementación autorizada: las versiones del robot de EV-021, en su orden, y el Sirius Work Engine.
- Prioridad vigente: la versión 0.2 del plan del robot, Sirius en texto: personalidad y memoria.

## Fuentes de verdad

1. `RECTOR.md`, con su §20
2. `DECISIONS.md`
3. `STATUS.md`
4. `AUDIT.md`
5. `ARTIFACTS.md`
6. `PLAN_DEL_ROBOT.md`, el plan aprobado versión a versión
7. `ENMIENDA_MANUAL_IDENTIDAD_2026-10.md`, la personalidad con las palabras del propietario

El documento rector define dirección, fronteras y puertas de producto. No sustituye las futuras definiciones de producto, planes de pruebas ni arquitecturas técnicas de cada versión. Para las versiones del robot, esas piezas son la sección de cada versión en `PLAN_DEL_ROBOT.md` y sus pruebas de aceptación, escritas antes del código (§20 del Rector).
